# Purpose 

I was writing a Operating System when I got really bored and annoyed of having to manually by hand calculate decimals, hexadecimals, and binary digits. I wrote this short Python script and ported it to my Ti-84 CE Python edition so that I could quickly convert numbers instead if having to do it by hand. 

# Instructions

If you for whatever reason wanted to put this on your own Ti-84 check if its in the supported calculator list and then follow these instructions. 

## FOR TI-84 EVO: 

1. Click on the Number Converter.py file and click "Download Raw File" (Or alternatively if your on Linux just pull this repo) 
<img width="1637" height="887" alt="image" src="https://github.com/user-attachments/assets/41c0524f-b176-453e-92a4-1772da4e5db8" />
2. Open Google Chrome on Windows (the transfer website sadly does not work on Linux) and go to https://connectevo.ti.com/ticevo/en/
3. Physically plug in your Ti-84 Evo into your computer, and then click connect on the ti connect website.
4. Click "Send File" and select the downloaded file from Step #1
5. After it is done transferring, open your calculator and select the "prgm" button
6. Click on Python
7. Click on "Number_C"

You may now use the program.
